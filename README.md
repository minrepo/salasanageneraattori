# Salasanageneraattori

Pieni Python-harjoitus, joka generoi satunnaisia salasanoja suomenkielisistä sanoista.

## Ominaisuudet

Salasanaan tulee:
* 3–4 satunnaista sanaa
* Satunnainen numero
* Satunnainen erikoismerkki

## Käyttö

```bash
python salasanageneraattori.py
```

Ohjelma tarvitsee samaan kansioon `sanalista.txt`-tiedoston (Kotuksen sanalista).
